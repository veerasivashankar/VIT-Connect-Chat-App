**VIT-Connect** is a real-time chat application inspired by WhatsApp, specially designed for **college students** to connect, chat, and build new connections with fellow students.
It provides a **modern, unique UI**, real-time messaging, multiple themes, and user presence tracking (online/offline).

---

## 📌 Project Overview

VIT-Connect allows users to:

* Register using **email and username**
* View **all registered users**
* Start **one-to-one real-time chats**
* See **online/offline status** of users
* Upload and display **profile pictures**
* Customize the app with **32+ beautiful themes**

This platform is mainly built to help **college students connect with different people** in a simple and engaging way.

## 🧠 How It Works

1. User registers or logs in using email & username
2. All registered users are displayed on the home page
3. User selects another user to start chatting
4. Messages are delivered instantly using Socket.IO
5. Online/offline status updates in real time
6. Users can upload profile pictures and change themes

## 🚀 Getting Started (Local Setup)

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/veerasivashankar/VIT-Connect.git
cd VIT-Connect
```

### 2️⃣ Install Backend Dependencies

```bash
cd backend
npm install
npm start
```

### 3️⃣ Install Frontend Dependencies

```bash
cd ../frontend
npm install
npm run dev
```
